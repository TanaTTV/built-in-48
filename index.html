FAQ

When does the 48 hours start?

Once I have your completed brief, payment, and any access I need (logins, API keys, content). If something's missing I'll tell you right away.

What if my project doesn't fit a package?

Message me for a custom build. If a brief you've paid for turns out to be too big for the package, I'll tell you before starting and refund you or suggest a fit.

What counts as a revision?

One round of changes to the delivered build, within the original scope. New features or a different project are a new order.

Do you do calls?

No calls needed. Everything happens by email so it stays fast and on the record.
